# Czech Forever

Complete Czech localization with Czech voice-over for **World of Warcraft: Forever**: quests, NPC dialogue, books,
the game interface and over 16,000 voiced lines.

Website: https://czechforever.cz

## Download

Get the newest version from **[Releases](https://github.com/MarrowB83/CzechForever/releases/latest)**:

- `CzechForever.zip` – the addon (texts, interface, voice player). Required.
- `CzechForever_Dabing*.zip` – the voice packs. Optional, for the Czech voice-over.

## Installation

1. Extract every zip into `World of Warcraft\_classic_beta_\Interface\AddOns\`. Each zip contains one folder.
2. Restart the game. New sounds and fonts load only when the game starts; `/reload` is not enough.

# Czech Forever (česky)

Kompletní čeština s českým dabingem pro **World of Warcraft: Forever**: questy, rozhovory s NPC, knihy, herní
rozhraní a přes 16 000 namluvených replik.

Web: https://czechforever.cz

## Stažení

Nejnovější verze je v **[Releases](https://github.com/MarrowB83/CzechForever/releases/latest)**:

- `CzechForever.zip` – addon (texty, rozhraní, přehrávač dabingu). Povinný.
- `CzechForever_Dabing*.zip` – balíčky dabingu. Volitelné, pro český dabing.

## Instalace

1. Každý zip rozbal do složky `World of Warcraft\_classic_beta_\Interface\AddOns\`. V každém zipu je jedna složka.
2. Spusť hru znovu. Nové zvuky a písmo se načtou jen při startu hry, `/reload` nestačí.
